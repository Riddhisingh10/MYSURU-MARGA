# Mysuru Marga Design System Guide

## Color Palette
The aesthetic draws from the heritage tones of the City of Palaces:
- **Cream Background:** `#F7F1E7`
- **Soft Ivory Cards:** `#FFFCF7`
- **Deep Maroon Accent:** `#702C3B`
- **Secondary Maroon:** `#8D4554`
- **Dark Charcoal Text:** `#282321`
- **Muted Brown:** `#776E68`
- **Beige Borders:** `#E5D8C8`
- **Restrained Green:** `#2D6A4F`
- **Muted Amber:** `#B07D14`

## Typography
- **Primary Font:** Plus Jakarta Sans / System UI
- **Hierarchy:**
  - H1 Page Title: 28px - 32px, Extrabold, tracking -0.02em
  - Card Titles: 16px - 18px, Bold
  - Body Text: 14px, Regular / Medium
  - Labels & Metadata: 11px - 12px, Semibold / Bold
